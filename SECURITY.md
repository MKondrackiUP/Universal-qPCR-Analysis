# Security policy

## Supported version

Security fixes are applied to the newest published release. The current development baseline is 0.22.0.

## Reporting a vulnerability

Until an institutional security contact is published, do not create a public issue containing exploit details or research data. Contact the repository owner privately and include only synthetic reproduction material.

## Security and privacy boundary

The default application is static and local-first. It has no user accounts, database or upload endpoint. qPCR files are parsed in browser memory and reports are generated locally. A hosting institution may still retain ordinary HTTP access logs according to its own policy.

This software is a research tool and must not be used as a clinical or diagnostic system.
