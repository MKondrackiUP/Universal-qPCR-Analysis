# Code of conduct

## Scope

This applies to everyone taking part in this project: issues, pull requests,
discussions and any other project space.

## Expected behaviour

Be respectful and constructive. Assume competence and good faith in others.
Critique the work rather than the person. Accept that a maintainer may decline a
change, and explain your reasoning rather than repeating it louder.

Because this is scientific software, two further expectations apply:

- Report the behaviour you actually observed, with a reproducible example built
  from synthetic data.
- Never attach real qPCR measurements, sample identifiers or any other research
  or personal data to an issue or a pull request. Synthetic reproduction
  material only.

## Unacceptable behaviour

Harassment, personal attacks, discriminatory language, and publishing another
person's private information without their consent.

## Reporting

Report a concern privately to the repository owner at the address in
`CITATION.cff`. Reports are handled confidentially as far as the maintainer is
able. A maintainer may edit, hide or remove contributions that conflict with
this document, and may block repeat offenders from the project spaces.

For a security vulnerability follow `SECURITY.md` instead.
